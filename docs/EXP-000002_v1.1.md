# EXP-000002 — Left Twin Prime Continuation

## Definition

`ltp(i)` is the `i`-th prime `q` for which `q + 2` is prime.

The adopted sequence begins:

```text
3, 5, 11, 17, 29, 41, 59, 71, 101, ...
```

Both 3 and 5 are included.

## Canonical large target

```text
observations: ltp(1) through ltp(100,000,000)
target:       ltp(100,000,001)
```

The stored dataset contains 100,000,001 values so the final value can remain a
private answer key.

## Representations

- `absolute`: consecutive left twin primes;
- `gaps`: consecutive differences between left twin primes;
- `combined`: current left twin prime and recent left-twin gaps.

## Conditions

- `hidden`: mathematical definition is not disclosed;
- `disclosed`: the left-twin definition is included in the prompt.

# PrimeAIExplorer v1.1.1 Maintenance Release

## Scope

This release contains no change to the mathematical definition, production
target, sampling design, or scoring contract of EXP-000002.

## Fixes

### Backward-compatible primality API

Both names are supported:

```python
is_prime_64
is_probable_prime_64
```

They refer to the same deterministic 64-bit Miller-Rabin function.

### Synthetic fixture

The finite synthetic repository is now tested against a target count and
endpoint that it actually contains. The production experiment remains:

```text
target_count = 100,000,001
endpoint     = 100,000,000
```

### Installer integrity

The installer uses native-command error propagation. A failed Python validator
or unit test aborts the installer and prevents a false success message.

## Release validation

The release is valid only when:

```text
v1.1.1 validator passes
compatibility tests pass
EXP-000002 synthetic tests pass
complete regression suite passes
```

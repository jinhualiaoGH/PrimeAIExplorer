# PrimeAIExplorer v1.3.0 Release Notes

PrimeAIExplorer v1.3.0 introduces:

- the Prime Value sequence plugin;
- atomic construction of 100,000,001 prime values;
- deterministic generation of 500 benchmark cases;
- blind prompts and public/private answer separation;
- response validation and scoring;
- per-window scientific reports;
- multi-model leaderboards;
- deterministic release manifests and source packaging.

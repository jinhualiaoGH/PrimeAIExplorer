## Freeze Rule

Phase H scientific contracts are immutable.

Subsequent phases may:

- consume Phase H contracts,
- wrap Phase H contracts,
- adapt Phase H contracts,
- persist Phase H outputs,
- verify Phase H outputs.

They must not silently redefine Phase H scientific identities or semantics.

Breaking changes require an explicit new versioned architecture contract.

# PrimeAIExplorer v1.2.1 Integration Fix

## Root causes corrected

### Script import root

Running a file as:

```powershell
py .\scripts\validate_v120.py
```

places the `scripts` directory, rather than the project root, first on
`sys.path`. v1.2.1 explicitly inserts the resolved project root before local
package imports.

### Verified Left Twin API

The actual v1.1.1 public implementation is the class:

```python
plugins.left_twin.LeftTwinPlugin
```

with these operations:

```python
validate_source()
build_dataset(overwrite=False)
validate_dataset(path=None)
load_dataset()
make_window(endpoint_index_1_based, window_size, representation)
structural_validity(prediction)
```

v1.2.1 delegates to this class and does not assume nonexistent module-level
dataset functions.

### Lazy built-in package

`sequence_plugins.builtin` no longer imports every implementation while its
package is initialized. Registry-based dynamic imports load only the selected
plugin.

### Installer integrity

Every Python command is followed by an explicit `$LASTEXITCODE` check.
Installation success cannot be reported after a validator or test failure.

## Scientific compatibility

EXP-000002 remains unchanged. Its one-based endpoint convention, canonical
left-twin definition, dataset extraction, metadata generation, and structural
validity are delegated to the verified v1.1.1 implementation.

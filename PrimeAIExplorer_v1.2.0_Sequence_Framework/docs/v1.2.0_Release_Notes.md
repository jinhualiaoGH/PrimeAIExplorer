# PrimeAIExplorer v1.2.0 Release Notes

## Added

- Generic `SequencePlugin` contract.
- CSV and JSON sequence-plugin registries.
- Dynamic plugin loading.
- Backward-compatible Left Twin adapter.
- Generic integer-sequence plugin.
- Prime Value plugin.
- Prime Gap plugin.
- Prime Square plugin.
- Generic case, prompt, and prediction-evaluation records.
- Plugin listing and validation commands.
- Sequence-framework regression tests.

## Preserved

- EXP-000002 configuration and scientific definition.
- Existing `plugins.left_twin` public API.
- `is_prime_64` and `is_probable_prime_64`.
- Connector, evaluation, observation, reporting, and execution contracts.
- v1.1.1 behavior.

## Deferred

The following identifiers are registry reservations only and remain inactive:

- `prime_cube`
- `oeis`
- `custom`

They cannot be loaded unless explicitly requested with an inactive-plugin
override. They are not represented as completed implementations.

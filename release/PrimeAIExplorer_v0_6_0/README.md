# PrimeAIExplorer v0.6.0 — Behavior Observatory

PrimeAIExplorer v0.6.0 extends the validated scientific observatory with behavior-level measurements: prediction persistence, switching, popularity, confidence realism, surprise ranking, and model fingerprints.

## Install
```powershell
cd C:\PrimeAIExplorer\release\PrimeAIExplorer_v0_6_0
.\install.ps1
.\run_tests.ps1
.\run_demo.ps1
```

New exports: `prediction_popularity.csv`, `persistence_runs.csv`, `confidence_realism.csv`, `surprise_index.csv`, and `model_fingerprint.csv`.

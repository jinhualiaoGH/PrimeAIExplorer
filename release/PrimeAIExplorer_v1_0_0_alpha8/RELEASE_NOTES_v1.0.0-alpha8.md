# PrimeAIExplorer v1.0.0-alpha8

Alpha8 adds a dependency-free SVG visualization layer and upgrades the unified dashboard from metric-first to visualization-first.

## Added
- `SvgVisualizationEngine`
- Publication-friendly standalone SVG files
- `figures.json` figure catalog
- Performance overview chart
- Prediction and truth distributions
- Persistence run-length chart
- Reliability diagram
- Confusion heatmap
- Surprise timeline
- Embedded charts in the self-contained dashboard
- Collapsible metric and table sections

The complete inherited workflow and legacy v0.7.3 compatibility remain available.

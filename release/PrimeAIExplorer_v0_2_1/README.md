# PrimeAIExplorer v0.2.1

PrimeAIExplorer v0.2.1 analyzes prime-gap prediction response JSON files directly against the canonical experimental dataset generated by `generate_dataset.py`.

## Main correction

Version 0.2.1 removes the duplicate manually maintained `truth.csv` workflow. The analyzer now reads `case_id`, `window_size`, and `ground_truth` from the canonical `cases.csv` dataset.

## Install

```powershell
cd C:\PrimeAIExplorer\release\PrimeAIExplorer_v0_2_1
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\install.ps1
.\run_tests.ps1
.\run_demo.ps1
```

## Locate the canonical dataset

```powershell
Get-ChildItem C:\PrimeAIExplorer\experiments\exp000001 `
    -Recurse `
    -File `
    -Filter cases.csv |
    Select-Object FullName, Length, LastWriteTime
```

Use the returned path below. A common location is `C:\PrimeAIExplorer\experiments\exp000001\data\cases.csv`, but the command deliberately does not assume the folder name.

## Validate and analyze pilot 001

```powershell
$Dataset = "PASTE_THE_FULL_CASES_CSV_PATH_HERE"

.\.venv\Scripts\paiexp.exe dataset-check `
    --dataset $Dataset

.\.venv\Scripts\paiexp.exe analyze `
    --responses C:\PrimeAIExplorer\experiments\exp000001\pilot_001 `
    --dataset $Dataset `
    --output C:\PrimeAIExplorer\experiments\exp000001\analysis_v021\pilot_001 `
    --model GPT-5.6-Thinking `
    --experiment-id EXP-000001 `
    --pilot-id pilot_001

.\.venv\Scripts\paiexp.exe verify `
    --analysis C:\PrimeAIExplorer\experiments\exp000001\analysis_v021\pilot_001

Start-Process C:\PrimeAIExplorer\experiments\exp000001\analysis_v021\pilot_001\report.html
```

## Analyze pilot 002

Use the same canonical dataset and change only the response and output paths:

```powershell
.\.venv\Scripts\paiexp.exe analyze `
    --responses C:\PrimeAIExplorer\experiments\exp000001\pilot_002 `
    --dataset $Dataset `
    --output C:\PrimeAIExplorer\experiments\exp000001\analysis_v021\pilot_002 `
    --model GPT-5.6-Thinking `
    --experiment-id EXP-000001 `
    --pilot-id pilot_002
```

The response search is recursive, so response JSON files may be stored directly under the pilot directory or in a nested subfolder.

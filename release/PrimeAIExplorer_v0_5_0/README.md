# PrimeAIExplorer v0.5.0 — Scientific Observatory

PrimeAIExplorer v0.5.0 extends the interactive collection workspace with behavior observatories for gap spectra, window effects, confidence, transitions, signed errors, gap families, and response timelines.

## Install

```powershell
cd C:\PrimeAIExplorer\release\PrimeAIExplorer_v0_5_0
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\install.ps1
.\run_tests.ps1
.\run_demo.ps1
```

## New exports

`gap_spectrum.csv`, `window_observatory.csv`, `confidence_histogram.csv`, `confidence_error.csv`, `error_distribution.csv`, `prediction_transitions.csv`, `gap_families.csv`, and `timeline.csv`.

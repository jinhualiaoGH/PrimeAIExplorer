# PrimeAIExplorer v1.0.0-alpha4

Milestone A4 introduces two first-class observatories:

- `CalibrationObservatory`: ECE, maximum calibration error, signed bias, over/underconfidence, reliability bins, and window calibration.
- `DistributionObservatory`: prediction/truth/error spectra, confusion structure, entropy, error direction, total variation, Jensen-Shannon divergence, and window distributions.

The release preserves the v0.7.3 compatibility workflow and all alpha1-alpha3 observatories.
